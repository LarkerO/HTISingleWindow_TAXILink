# 品牌与乘客端轮播（待发布）

console 页首、登录页及 Vue v1 页首使用仓库根目录 logo.png 的静态副本，随前端构建发布，不依赖 COS。原始文件保留。

平台管理员在 console「轮播卡片」配置；主页与行程底部位置分别设置，按列表顺序每 5 秒轮播，可上移、删除、启停。展示宽高为逻辑像素（40–1600），窄屏等比例缩小；图片按比例完整显示。Vue v1 与 TMUI 的主页轮播位于主按钮之后，行程轮播位于信息容器底部。

使用现有上传服务（可选择 COS）上传，或选择最近 200 条上传审计中的图片；旧记录按当前 COS 配置还原公开地址，桶/域名曾改动时应填写原图 URL。不枚举云桶，不需要额外的云管理权限。上传成功日志保存图片公开 URL，以后改默认存储不影响历史地址。已上传图片也可直接填写 HTTPS URL。

点击可进入公告页（下架、登录限制继续由公告接口执行），或打开 HTTP/HTTPS 外链；Web 使用新窗口并隔离 opener，原生 App 交由系统浏览器处理。允许为 home/trip 分别配置相同图片。

接口：GET /api/carousel 公共只返回启用卡片；GET/POST /api/admin/carousel 限平台管理员；GET /api/admin/media/library 限平台管理员。配置存已有 system_settings，无新增数据库表，不重新安装或 seed。保留数据库、installation 密钥和原 COS 对象；没有配置时两端不显示占位，不影响旧客户端；回滚代码保留配置即可。

验证包括权限、非法外链、尺寸、公告存在性、重复迁移保留数据，两个乘客端轮播显示与新窗口跳转。未使用真实云凭据写入测试。本轮仅源码，不发版、不部署。
